This question deals with equivalence checking between a rtl file and it's netlist file (generated by yosys)

The flow was 

    1) Write the rtl with some redundant logic
    2) Synthesize it using yosys (with proc opt and such flags) which removes the redundant logic by creating a reduced order binary decision diagram
    3) Take the rtl and its synthesized netlist (the two .v files) and run them through another yosys script by creating them into a miter circuit to perform equivalence check

The order of files are 

    ques4.v -> The RTL
    ques4a.ys -> Takes the RTL and makes the netlist
    ques4b.ys -> Takes the RTL and Netlist and checks equivalance
